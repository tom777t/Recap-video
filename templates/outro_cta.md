# Outro CTA Template

Use as structure for U_outro unit. Customize per film.

## Structure (40-60 words total)

**[THEMATIC CLOSURE] (~25-30 words):**
Synthesize film's central theme in 1-2 sentences. Reference back to
hook's thematic teaser if possible (frame closure).
Examples:
- Reference moral question raised: "X is a story about how far a
  person can fall when [theme]."
- Reference mystery resolved: "X reveals that the truth was [insight]
  all along."
- Reference character arc: "X is about [character archetype]
  discovering [discovery]."

**[CTA] (~15-25 words):**
Standard call-to-action format:
"Thanks for watching. If you enjoyed this, hit like and subscribe for
more [content type - deep dives / recaps / reviews]. See you in the
next one."

Adjust phrasing for channel voice but keep structure: thanks -> like +
subscribe -> next video transition.

## Visual binding:

Bind outro lines to CLOSURE footage:
- Ambiguous ending shots (preserves film's intended emotional landing)
- Aftermath shots (post-climax breathing room)
- Atmospheric closing beats (location returns, time passing)

AVOID binding to:
- New plot reveals (creates confusion after closure)
- Mid-film action shots (jarring tone)
- Hook footage reuse (feels lazy circular)

## Example (Prisoners 2013):

> "Prisoners is a story about how far a person can fall when love
> turns into rage - and how the truth was right next door the whole
> time.
>
> Thanks for watching. If you enjoyed this, hit like and subscribe
> for more deep dives. See you in the next one."
